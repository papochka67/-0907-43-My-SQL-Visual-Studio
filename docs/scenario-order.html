Сценарий оформления заказа в ShoeShop

Дорожка Шаг процесса Тип элемента BPMN Условие или результат
Покупатель Начало оформления заказа Начальное событие Покупатель открыл корзину и готов оформить заказ.
Покупатель Покупатель выбирает товары Задача В корзине сформирован список позиций.
Приложение ShoeShop Приложение запрашивает остатки Задача Сформирован запрос к БД по выбранным товарам.
База данных БД проверяет остатки Задача Получены текущие остатки по каждой позиции.
Приложение ShoeShop Приложение делает шлюз «Все товары в наличии?» Шлюз (исключающий) Проверяется, что остаток ≥ количества в корзине по всем позициям.
Покупатель Ветка ДА: Покупатель подтверждает заказ Задача Покупатель нажимает «Оформить» и выбирает ПВЗ.
Приложение ShoeShop Приложение создаёт заказ Задача Формируется запись заказа и строк заказа.
База данных БД сохраняет заказ Задача Заказ и строки записаны в БД в одной транзакции.
Приложение ShoeShop Приложение показывает код получения Задача Клиент видит код заказа и статус «Новый».
Покупатель Конец (ветка ДА) Конечное событие Заказ успешно оформлен.
Приложение ShoeShop Ветка НЕТ: Приложение показывает сообщение Задача Выводится сообщение «Часть товаров отсутствует на складе».
Покупатель Покупатель меняет корзину Задача Покупатель возвращается к выбору товаров; процесс повторяется.
