# Магазин обуви «Подошва»

## Описание

Приложение для небольшого магазина обуви. Клиент просматривает каталог, подбирает обувь по фильтрам (размер, цвет, цена, бренд) и оформляет заказ. Продавец-консультант ведёт каталог, следит за остатками по размерам и меняет статусы заказов. Администратор управляет пользователями и их правами.

Подробнее о проекте: [паспорт проекта](docs/passport.md).

## Технологии

- **Язык:** C#
- **Среда разработки:** Visual Studio
- **База данных:** MySQL, проектирование и работа в MySQL Workbench

## Как запустить

1. Установите Visual Studio и MySQL Workbench.
2. Клонируйте репозиторий:

   ```
   git clone <ссылка на репозиторий>
   ```
3. В MySQL Workbench выполните скрипты создания базы данных.
4. Откройте решение (`.sln`) в Visual Studio, укажите строку подключения к базе и запустите проект.
